# MIPT Prompts CTF

Веб-платформа с заданиями по prompt injection. Пользователь атакует языковую модель Google Gemini: вытаскивает секрет из системного промпта, заставляет ИИ признаться что он не человек, ломает политику корпоративного ассистента. Бэкенд на FastAPI, хранение в SQLite, регистрация с подтверждением почты.

Ссылка на сайт: https://miptctfprompts.work.gd

## Что внутри

Три трека заданий:

- `gandalf` - вытащить секретное слово из системного промпта, обходя фильтры на входе и выходе. Сложность растёт от уровня к уровню.
- `confess` - многоходовой диалог, нужно заставить персонажа (репетитор, оператор поддержки, психолог и т.д.) признать что он нейросеть. Проверка через отдельную модель-судью.
- `story` - корпоративные сценарии по мотивам реальных инцидентов (банк, авиакомпания, страховая). Нужно нарушить политику ассистента.

Технически:

- FastAPI + Jinja2, ASGI-сервер uvicorn.
- SQLite через SQLAlchemy: пользователи, прогресс, дневные квоты, диалоги.
- Авторизация по email с подтверждением (bcrypt для паролей, подписанные cookie через itsdangerous).
- Описания уровней в YAML вне репозитория, читаются при старте.
- google-genai SDK в режиме Vertex AI, трафик к Gemini идёт через локальный SOCKS5-прокси для обхода геоблока.
- Дневная квота на пользователя плюс глобальный rate limit, чтобы анонимы не жгли кредиты GCP.
